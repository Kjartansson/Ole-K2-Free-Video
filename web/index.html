      How to make a video
      
    
        
      
      1. Story tab: write the idea and click Write story (local AI), or copy the prompt to ChatGPT/DeepSeek and paste the answer into the Script box. Click Check.
        2. 
      
      2. Give it a project name and an output file name, click Save as new project.
        3. 
      
      3. Scenes tab: fix any scene. Preview renders one scene so you can check it fast. New picture tries another seed.
        4. 
      
      4. Render tab: pick options (or keep the defaults) and click Render video.
        5. 
      
      5. When it is done: copy the caption, open the exports folder and upload the MP4 to TikTok yourself.
        6. 
    
      
    
      Picture engines
      
    
        
      
      • Image + LTX animation: a still for each scene, then LTX makes it move. Best balance.
        • 
      
      • Image + camera move: a still with a smooth zoom/pan. Fastest, works on small cards.
        • 
      
      • LTX text-to-video and Wan 2.1: video straight from the text (less control).
        • 
      
      • My own clip: upload a clip or picture on a scene card.
        • 
    
      
    
      Long videos (up to 15 minutes)
      
    
        
      
      • Pick a length of 2-15 min. The local AI plans chapters first, then writes them one by one.
        • 
      
      • From ChatGPT/DeepSeek: the copied prompt asks for one chapter per answer. Write "next" for the
        next chapter and paste all answers one after another into the Script box.
        • 
      
      • Plain story text without scenes also works: every sentence or two becomes a scene. Convert with local AI
        gives better pictures and handles long texts in parts.
        • 
      
      • The factory splits long lines into extra shots, crossfades every cut, keeps sounds running across cuts,
        changes the music per chapter and shows chapter titles. The Render tab shows how long it will take.
        • 
    
      
    
      No GUI? Use the command line
      
    
      ./factory.sh make my-story.txt           # text file -> finished video
./factory.sh write "an idea" my-story.txt  # local AI writes the script file
./factory.sh                               # start the GUI
      
    
      Nothing here uses the cloud. Nothing is posted automatically.
      
  
      
  
      
    
      Recent problems
      
    
      Every error is kept in logs/errors.jsonl with a ref, a code and a hint. Copy report
      gives everything needed to fix it (paste it to Claude or Kimi). In a terminal: ./factory.sh errors or
      ./factory.sh report.
